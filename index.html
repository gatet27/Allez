Fonctionnement et import manuel

La première image dans l’ordre de la galerie Shopify est l’image principale. Elle est exclue, ainsi que ses doublons d’URL (paramètres ignorés) et toute image principale explicitement déclarée. Les autres photos de la galerie, y compris celles des variantes, sont exportées. Logos, descriptions et vidéos sont ignorés. Les copies réimportées avec un autre identifiant et une autre URL ne peuvent pas être reconnues visuellement.

Le catalogue fourni avec ce fichier est un instantané du 28 octobre 2026. « Actualiser » parcourt toutes les pages du catalogue public, sans limite à 177 ou 250 produits. Les produits non publiés ne sont pas accessibles. Si le site bloque la lecture dans votre navigateur, l’instantané reste disponible. Aucun proxy tiers n’est utilisé.

Vous pouvez aussi ouvrir le catalogue JSON, l’enregistrer, puis importer les fichiers de toutes les pages non vides. Attention : un import ne garantit pas que vous avez fourni toutes les pages.

Le ZIP est préparé dans la mémoire de votre navigateur. Gardez cet onglet ouvert pendant le téléchargement. Si une image échoue, le ZIP contient les images réussies et un rapport d’erreurs ; vous pouvez ensuite relancer l’export.

Le filtre concerne les aperçus. L’export inclut toujours toutes les images secondaires du catalogue chargé.
